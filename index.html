Research & project file management

Private project synchronization with Google Drive.

rclone_server is a personally maintained configuration of rclone that helps its owner synchronize research projects and other personal files between computers, servers, and Google Drive.

This website describes the OAuth application. It is not a login portal, synchronization service, or public file-sharing platform.

How it works

Simple, owner-controlled cloud synchronization

Local configuration

The owner runs rclone on personal devices or servers and controls all synchronization commands and destinations.

Google Drive API

Google OAuth grants rclone the access needed for owner-requested file operations. The actual permissions are shown during authorization.

No public service

This site does not accept registrations, store OAuth tokens, or host project files. The application is not offered to the public.

Google Drive access

Depending on the OAuth scope granted and the owner's rclone settings, operations may include listing, reading, uploading, updating, moving, or deleting Google Drive files. Access is used only for file management and synchronization initiated by the account owner.

For details about data access, local storage, sharing, and revocation, see the Privacy Policy.
